# Cart 车架刚体模式：碰撞保真测试场景设计

## 目标与边界

本场景回答的不是“整车能否行驶”，而是：当 Cart 作为一个**固定的管状车架**时，PhysX collider 是否只占据可见金属管件应占据的空间，且不会在可见空隙中产生空气墙。

这是碰撞形状保真测试。脚轮转动、质量、摩擦、关节极限、整车倾覆和动力学稳定性均不在本轮结论内。

## 临时测试场景

输入资产为 `cart_v2.usda` 或其 safe repair candidate。测试生成独立 USDA，引用输入资产；绝不回写输入资产。

| 元素 | 设定 |
|---|---|
| 车架 | 固定的 collision-only 几何；移除 `RigidBodyAPI`、`MassAPI` 与 PhysX 刚体 API |
| 关节 | 在生成的测试 stage 内 `active = false`，不解析或驱动 articulation |
| 重力 | 0 m/s²，排除落地和脚轮姿态造成的变量 |
| 车架碰撞 | 仅保留输入资产已 author 的 `CollisionAPI` collider；绝不为了测试给全部可见 Gprim 补 collider。Cylinder 应保持 cylinder，而不是用 convex hull 或 SDF 包裹一组管件 |
| 探针 | 单一 dynamic Sphere，质量 1 kg、无初始角速度、恒定初速度 |
| 读数 | Isaac Sim PhysX contact report；只有 `contact_detected = true` 才是“命中管件”的通过证据 |

现有资产有 13 个刚体与 12 个 joint；上述冻结只发生在诊断 stage，不能作为整车 articulation 的运行时结论。

## 坐标、尺寸与基线

当前 Cart 外包围范围约为 X 0.375 m、Y 0.378 m、Z 0.590 m（底部约 Z=0.12 m，上框约 Z=0.71 m）。初始基线使用：

- 球半径：40 mm；
- 速度：0.50 m/s；
- 频率：60 Hz；
- 时长：240 帧；
- 方向：`+X`、`-X`、`+Y`、`-Y`。

球的起点放在待测 collider 外，距车架至少 `max(3r, 80 mm)`；因此初始帧不应重叠。

## 测试矩阵

### P：正例——应命中可见管件

每个侧面在以下五个高度各选择一个实际的 Frame collider，并使球沿局部外法线进入：

1. 轮区 / 底部 cradle；
2. 下横杆；
3. 斜撑；
4. 侧向轨道；
5. 顶部框架。

第一轮只运行每个方向一个最外侧 Frame 管件，用来验证场景、接触报告和坐标方向；后续扩展至完整 20 个正例。

通过条件：接触报告中同时出现 `/World/ProbeSphere` 和 `/World/InputAsset/.../Frame/...`。仅观察球减速或位移变化不算通过。报告还必须列出“author 的 collider 数”和“测试中 active 的 collider 数”，两者不相等即测试无效。

### N：负例——应穿过可见空隙

每个侧面至少选四个明确开口：立柱之间、上下横杆之间、顶部中央开口、底部框架中央开口。球沿相同方向通过，轨迹不能碰到任何可见管件。

通过条件：在限定帧数内没有与车架的 contact report，且最终位置已越过车架相对侧包围面 80 mm。

失败条件：视觉射线路径为空，但发生接触；这就是空气墙候选。

### C：角点与斜向

用 45° 入射测试四个上框角，以及斜撑与横杆交汇处。该组专门检出 convex hull 把凹口或两根独立管件之间的空间填满的情况。

### S：尺寸扫掠

对每一个 N 组开口使用 10、25、40 mm 三种半径。报告开口最小可通行半径，而不是把窄缝不可通行误判为空气墙。

## 量化判据

沿球运动射线同时求视觉 mesh 的首个交点与 PhysX 首次接触时球心位置：

`空气墙误差 = PhysX 首次接触的球面位置 - 视觉首交点`

| 结果 | 判定 |
|---|---|
| 绝对误差 ≤ 2 mm | 通过 |
| 2–5 mm | 警告，保留截图与路径 |
| > 5 mm | 失败 |
| 视觉空隙内发生 contact | 失败：空气墙 |
| 视觉管件上无 contact | 失败：漏碰 |

外部 AABB 对齐只能证明整体尺寸一致，无法证明管件之间的空隙正确，因此不能代替 P/N/C/S 矩阵。

## 输出与复现

每一个 case 目录必须包含：生成的 USDA、`sphere_probe.json`、首次接触记录、探针轨迹、输入资产 SHA256、Docker 容器/镜像、命令行和失败分类。截图须同时显示可见车架、collider overlay、球轨迹和首接触点；不能仅使用整车暗色鸟瞰图。

首轮产物路径为 `out/cart_frame_rigid_body_probe/<side>/sphere_probe.json`。正例完成后，才增加空隙负例与视觉首交点的毫米级比对。
